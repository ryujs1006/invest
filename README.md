# ASSET RADAR v1

개인용 글로벌 자산 순환매 모니터링 PWA의 1차 실행 버전입니다.

## 포함 기능
- 국내/미국/유럽/일본/베트남/아시아/아세안/인도 주식 및 채권·원자재·외환·리츠·커버드콜 ETF 모니터링 목록
- TradingView 시장 시세 위젯 및 종목별 차트 임베드
- 자산 검색 및 자산군 필터
- 관심자산 로컬 저장
- 매입 단가·수량·일자·메모 기록 및 CSV 내보내기
- 네이버증권 리서치 및 상품 공식 사이트 바로가기
- PWA manifest 및 service worker

## GitHub Pages 배포
1. GitHub에서 새 Public repository를 만듭니다. 예: `asset-radar`
2. ZIP 압축을 풀고 `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `icons/`를 저장소 최상위(root)에 업로드합니다.
3. Repository > Settings > Pages로 이동합니다.
4. Build and deployment에서 `Deploy from a branch`를 선택합니다.
5. Branch `main`, Folder `/ (root)`를 선택하고 Save 합니다.
6. 배포된 `https://<GitHub아이디>.github.io/asset-radar/` 주소를 iPhone Safari로 엽니다.
7. 공유 버튼 > 홈 화면에 추가를 선택합니다.

## 현재 버전의 범위와 제한
- 시세/차트는 TradingView 임베드 위젯을 사용합니다. 거래소·상품별 실시간 제공 여부와 지연시간은 데이터 라이선스 및 위젯 정책에 따릅니다.
- 임베드 차트의 티커는 지수 또는 ETF 대체지표(proxy)가 포함됩니다. 정확한 지수/현물/선물/ETF가 다를 수 있으므로 화면의 티커를 확인해야 합니다.
- 초록/노랑/빨강 상태는 검증된 밸류에이션·수급·펀더멘털 데이터 파이프라인이 연결되기 전까지 `판정 보류`입니다. 가격 하락만으로 저평가 판정을 내리지 않습니다.
- 네이버 리서치 자동 수집 및 AI 요약은 아직 연결하지 않았습니다. 원문 링크만 제공합니다.
- 우리투자증권 펀드 및 나무증권 ETF TOP 10은 공식 판매·거래 가능 데이터가 연결되기 전까지 임의 수익률을 표시하지 않습니다.
- 관심자산/매입 기록은 해당 브라우저의 localStorage에 저장되며 기기 간 동기화되지 않습니다.
- 투자 판단용 데이터 서비스가 아니며, 투자 권유 또는 수익 보장을 하지 않습니다.
